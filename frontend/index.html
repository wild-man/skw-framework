What this chat is

A local LLM (qwen3:4b-instruct on Ollama, running on my own GPU) answering through the skw2 backend this site runs on: a Rust system of an HTTPS gate and a WebSocket gate, the Iggy message bus, RabbitMQ workers, Postgres and Redis. The dialog service stores each conversation, queues your question and has the model answer it; the page shows the answer when it is ready.

Tools the model can use

Read-only access to the skw2 source code (this page included; secrets and configs are hidden). The model picks them itself, or start a message with the command to run one directly, without the model:

  • /list_files [dir] [depth]: lists a directory of the project
  • /search_text <text> [dir=<dir>] [ext=<ext>]: finds a text in the source files
  • /read_file <path> [start] [end]: reads lines of a file
  • /show_file <path>: shows a whole file exactly as it is
  • /diagrams: shows the architecture diagrams as previews; click one to open it full size
  • /help: lists these commands

Try: "How does the ws gate verify signatures?", "Show me services/dialog/src/lib.rs", "Show me the diagrams". It is a small 4B model, so answers can be incomplete. Send ? any time to see this help again.
